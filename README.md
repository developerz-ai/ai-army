# ai-assitant-army

An AI Army project powered by the [ai-army](https://github.com/developerz-ai/ai-army) framework.

## Quick Start

```bash
npm install
npx ai-army validate
docker-compose up -d
npx ai-army migrate
npx ai-army start
```

## Bots

- **assistant** - A general-purpose AI assistant
